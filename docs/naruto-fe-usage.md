# naruto-fe VIP 解鎖

## 功能
- 解鎖火影忍者社區微信小程式 VIP 會員
- 偽造用戶 vip 狀態 = 1，添加 vip_member 標識

## 技術細節
- 後端：騰訊雲 uniCloud（單一端點 invokeFunction）
- 端點：`env-00jxgsbzdqch.api-hz.cloudbasefunction.cn`
- 集合：`uni-id-users`
